# AICodeT

AI와 함께 소프트웨어를 만드는 방법과 코딩 기초를 배우는 실습형 학습 웹앱입니다.

## 프로젝트 상태

현재 기획 단계입니다. 이 저장소는 기획과 개발 과정, 사용자 피드백에 따른 개선 이력을 관리합니다. 아래 기능은 구현 예정이며, 아직 실행 가능한 앱은 없습니다.

## 해결하려는 문제

AI로 코드를 만들어본 입문자가 요구사항을 구체화하고, 생성된 코드를 이해하며, 오류와 결과를 스스로 판단하도록 돕습니다. 이 문제 가설은 초기 사용자 테스트를 통해 검증할 예정입니다.

## 학습 구성

### AI 개발 가이드

짧은 설명 카드와 예시, 작은 질문으로 AI와 개발하는 흐름을 익힙니다.

- 해결할 문제와 사용자를 정하기
- 요구사항과 완료 기준 구체화하기
- 작업을 작은 기능으로 나누기
- AI에게 현재 상태, 목표, 제약 전달하기
- 계획, 구현, 검증을 반복하기
- 변경을 기록하고 되돌리기
- 사용자 피드백으로 개선하기

### 코딩 기초

입력·처리·출력, 변수, 조건문, 함수, 배열, 객체, 이벤트와 브라우저 저장을 실습과 연결해 학습합니다.

### 프로젝트 실습

할 일 관리 앱을 주제로 요구사항 작성부터 기능 구현, 코드 이해, 오류 수정, 데이터 저장, 독립적인 기능 확장까지 경험하도록 설계합니다.

## 첫 구현 범위

- 학습 홈: AI 개발 흐름, 개념 카드, 학습 이어가기
- AI 개발 가이드: 주제별 설명과 실습 연결
- 코딩 기초: 쉬운 예시와 개념 찾아보기
- 실습 화면: 미션, 코드 편집, 실행 결과와 피드백
- 학습 기록: 진도, 작성 내용, 검증 결과

처음에는 준비된 예제와 피드백을 사용하며 AI 응답 예시임을 명시합니다. 실제 AI 힌트 기능은 학습 흐름을 검증한 뒤 검토합니다.

## 개발 및 검증 계획

1. 오류 수정 미션 하나를 설명부터 실행·피드백까지 구현합니다.
2. 초보자 3~5명의 사용 과정을 관찰합니다.
3. 관찰한 어려움을 바탕으로 화면과 설명을 개선합니다.
4. 다른 미션으로 확장하고, 새로운 문제에 배운 방법을 적용할 수 있는지 확인합니다.

테스트 결과는 실제 관찰 후 기록하며, 문제 가설·설계 이유·변경 사항·검증 결과를 구분해 남깁니다.
