# AICodeT

AI와 함께 소프트웨어를 만드는 방법과 코딩 기초를 배우는 모바일 학습 앱입니다. Android에서 먼저 확인하며, 설명 → 이해 확인 → 제한된 실습 → 결과 검증을 연결하는 것이 목표입니다.

## 현재 구현

- 학습 / 방법론 / 내 기록 세 메뉴와 홈의 **AI 코딩 개발 방법론** 버튼
- 하네스 상세 설명, 컨텍스트·프롬프트 요약, 근거 링크와 발행·확인일
- 첫 학습 ‘빈 할 일이 추가되는 이유’: 개념, 네 문항, 오답 재시도, 정답 설명, 이해 확인 완료
- 공백 처리·빈 값 차단 코드 조각을 선택하고 세 입력의 실제 결과 비교
- AsyncStorage로 단계·답·실습 결과 저장·복원, 저장 실패 시 재시도, 확인 후 기록 초기화

실제 AI 호출과 자유 코드 실행은 구현하지 않았습니다. 이해 확인과 세 입력의 실행 검증을 모두 통과해야 오류 수정 미션 완료로 표시합니다. 앱스토어에 배포하지 않았습니다. SDK 58 전환 직후 Android Expo Go에서 정상 작동한다는 사용자 보고를 받았으며, 이번 실습·저장 기능의 실기기 확인과 iOS·사용성 평가는 아직입니다.

## 실행

Node 24.19.0, npm 11.17.0을 기준으로 합니다. 패키지와 잠금 파일은 저장소 루트에 있습니다.

먼저 npm ci로 설치하고 npm start로 개발 서버를 실행합니다.

Android에 SDK 58을 지원하는 Expo Go를 준비하고 컴퓨터와 같은 네트워크에서 개발 서버의 QR 코드 또는 표시된 주소로 연결합니다. 네트워크 환경에 따라 연결 확인이 필요합니다. Expo Go 실행은 독립 APK 설치나 스토어 출시와 다릅니다.

원문 링크 외의 콘텐츠는 앱에 포함됩니다. 저장이 끝난 학습 기록은 앱을 다시 열어 복원할 수 있습니다. 다른 기기로 동기화되지 않으며 앱 데이터 삭제 시 기록이 사라질 수 있습니다. 저장 실패는 화면에 표시하고 재시도를 제공합니다.

## 검증

npm run typecheck, npm run lint, npm test, npm run check:dependencies, npm run doctor, npm run export:android를 사용합니다.

2026-11-09: Expo Go의 버전 불일치에 대응해 SDK 58로 전환했습니다. 전환 당시 Expo 호환 검사와 환경 진단 20개가 통과했습니다. 실습·저장 추가 후 타입·린트, 학습·실행·저장 테스트 33개, Android 번들 생성을 확인했습니다. 재시작한 개발 서버의 Android manifest가 SDK 58.0.0으로 응답하는 것도 확인했습니다. 번들 생성과 서버 응답 확인은 네이티브 기기 실행 검증이 아닙니다. npm audit에는 후속 검토가 필요한 의존성 경고가 남아 있습니다. 정확한 버전·검증 범위·경고는 [도구와 버전](docs/TOOLCHAIN.md)에 기록합니다.
