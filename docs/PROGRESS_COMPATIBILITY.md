# 진도 기록 호환 정책

작성일: 2026-11-10. 현재 저장 형식·콘텐츠 버전은 각각 1이며 이번 작업에서 바꾸지 않았습니다. 아래는 변경 시 적용할 정책입니다. 아직 존재하지 않는 버전의 자동 변환을 구현했다고 주장하지 않습니다.

## 변경별 처리

| 변경 | 버전 처리 | 기존 기록 처리 |
| --- | --- | --- |
| 레이아웃·오탈자·정답 의미가 바뀌지 않는 설명 수정 | 기록 해석에 영향이 없다면 버전 유지 | 그대로 복원 |
| 문제·선택지 순서, 정답, 완료 기준, 실행 예제 변경 | contentVersion 증가 | 새 의미로 답 인덱스를 해석하지 않음. 변경에 맞춘 변환이나 재학습 정책이 검증되기 전 배포하지 않음 |
| 저장 필드·자료 형태 변경 | schemaVersion 증가 | 이전 형식을 검증하고 명시적인 단계별 변환 수행 |
| 앱보다 새로운 버전의 기록 | 읽기 차단 | 원본 보존. 조용히 이전 형식으로 덮어쓰지 않음 |
| 손상되거나 미지원인 기록 | 읽기 차단 | 현재 구현처럼 재시도와 사용자 확인 후 초기화 제공 |

현재 답은 배열의 인덱스로 저장됩니다. 따라서 문제 id가 같더라도 선택지나 문제 순서를 바꾸면서 contentVersion을 유지하면 안 됩니다. 단순히 버전 숫자를 허용하도록 수정하는 방식도 금지합니다.

## 실제 버전 변경을 구현할 때의 완료 기준

1. 배포된 이전 버전의 기록 예제와 변경된 콘텐츠를 함께 준비합니다. 예제에는 진행 중·완료·복습·실행 결과가 포함됩니다.
2. 변환 전 원본을 앱 전용 백업 키에 보관합니다. 백업 실패 시 원본을 덮어쓰지 않습니다. 저장된 답이 개인정보를 포함하도록 범위를 바꾼다면 백업·삭제 정책도 다시 검토합니다.
3. 내용과 정답 의미가 같은 경우에만 문제·선택지 id로 대응합니다. 대응할 수 없는 답과 실행 결과를 완료로 인정하지 않습니다.
4. 사용자에게 유지된 기록과 다시 확인할 내용을 설명합니다. 이전 완료 이력과 새 버전의 현재 완료 여부를 구분합니다.
5. 변환 결과를 검증한 뒤 기존 저장 순서 제어를 통해 새 기록을 저장합니다. 도중 종료·저장 실패·재시도를 검사합니다.
6. 기록 초기화가 백업을 포함한 앱 전용 학습 키만 제거하도록 함께 수정합니다.

현재는 버전 1만 지원하며 자동 이전·백업 기능은 없습니다. 향후 콘텐츠 확장과 동시에 해당 변환을 구현하고 기기에서 검증해야 합니다.
