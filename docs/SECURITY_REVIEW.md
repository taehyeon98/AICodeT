# 의존성 안정성 검토

확인일: 2026-11-10. 이번 검토는 확인 범위와 남은 위험을 기록하며 취약점 해소나 배포 승인을 의미하지 않습니다.

## 확인한 결과

- npm audit: 낮음 1, 중간 28, 높음 0, 치명적 0, 총 29개. 동일 하위 경고가 상위 패키지에 전파된 집계를 포함합니다.
- npm audit fix --dry-run: 추가 8·제거 8·변경 17을 제안하지만 결과 집계는 동일한 29개입니다. 패키지 재배치와 일부 검사 도구 갱신만으로 경고가 해결된다고 볼 수 없어 적용하지 않았습니다.
- package.json·package-lock.json·설치된 패키지 버전은 변경하지 않았습니다. --force나 override를 사용하지 않았습니다.
- 분석용 Android export와 소스맵 생성에 성공했습니다. 소스맵의 1,148개 원본 경로에서 glob·minimatch·deepmerge 패키지 경로는 발견되지 않았습니다. src에서도 이 패키지를 직접 사용하지 않습니다.
- 이는 이번 Android JavaScript 산출물에서 확인한 범위입니다. 개발 서버·빌드 도구·CI의 위험이 없어졌다는 뜻이나 전체 네이티브 앱 보안 검증은 아닙니다.

## 경고별 판단

| 항목 | 설치 경로와 조건 | 공식 수정 상태 | 현재 처리 |
| --- | --- | --- | --- |
| glob | Expo CLI/fingerprint와 Jest에서 사용. 비동기 파일 탐색을 취소해도 작업이 이어져 자원을 사용할 수 있는 문제 | 14.0.2에서 수정. 현재 트리에는 13.0.7·10.5.0 등이 있어 주요 버전 변경 검토 필요 | 상위 패키지의 호환 업데이트를 확인한 후 적용. 강제 교체 보류 |
| minimatch | Expo·ESLint·Jest 경로. 공격자가 제공한 패턴과 최적화 조건에서 자원 소모 가능 | 11.0.1에서 수정. 현재 관련 경로는 10.2.6·9.0.9 등 | 각 상위 도구와 호환성을 확인하기 전 강제 교체 보류 |
| deepmerge | Jest 설정 처리 경로의 4.3.1. 병합하는 객체가 조작될 때 결과 객체의 프로토타입 오염 가능 | 조회한 공식 보안 안내에는 수정 버전 없음 | 검토되지 않은 외부 설정·객체를 테스트 구성에 병합하지 않음. 상위 수정 추적 |

근거: [glob 보안 안내](https://github.com/advisories/GHSA-3g3m-2fjr-6pw4), [minimatch 보안 안내](https://github.com/advisories/GHSA-g3hv-75wg-m249), [deepmerge 보안 안내](https://github.com/advisories/GHSA-gcqx-w48m-w2h4).

현재 앱은 임의 사용자 코드를 실행하거나 사용자 지정 파일 패턴을 이 도구들로 전달하지 않습니다. 이 점과 산출물 확인을 근거로 휴대폰의 현재 학습 흐름에서 직접 노출되는 경로는 발견하지 못했습니다. 개발·CI에는 경고가 남아 있으므로 안전하다고 단정하지 않습니다.

## 다음 조치와 재검토 조건

- 상위 Expo·Jest·ESLint가 수정된 의존성을 지원하면 작업 브랜치에서 설치·잠금 파일·문서를 함께 갱신하고 전체 CI를 확인합니다.
- 사용자 파일 업로드, 임의 코드 실행, 외부 설정 입력을 추가할 때는 해당 입력 경로를 다시 검토합니다.
- GitHub 검사에는 비밀키를 제공하지 않고 저장소 읽기 권한만 사용합니다. 현재 높은 등급 이상의 보안 경고는 CI 실패 조건입니다.
- 독립 APK 배포 전 다시 조회하고 실제 배포 산출물·동작을 확인합니다. 이 검토만으로 남은 경고 수정 항목을 완료 처리하지 않습니다.
