# AICodeT 시연 대본과 제출 준비

정리일: 2026-11-10. 약 3~4분 분량의 녹화 준비안입니다. 실제 영상이나 화면 캡처는 아직 없으며, 독립 APK 설치 확인과 사용자 관찰은 요청에 따라 보류했습니다.

## 짧은 프로젝트 소개문

AICodeT는 AI와 함께 개발할 때 필요한 문제 설명·코드 이해·결과 검증을 배우는 Android 학습 앱입니다. 첫 미션에서 빈 할 일 오류를 관찰하고, 원하는 동작을 정리한 뒤, 코드 조각을 선택해 빈 입력·공백·정상 입력의 실제 결과를 비교합니다. 학습 상태와 실행 검증을 구분하고, 진도 저장의 순서·실패·초기화까지 설계했습니다. 핵심 로직 테스트 33개와 PR 자동 검사를 통과했으며, 독립 APK 생성·서명 검사까지 완료했습니다. APK의 실제 기기 실행과 입문자 사용성 관찰은 아직 수행하지 않았습니다.

## 녹화 전 원칙

- 실제 실행 환경을 먼저 표시합니다. Expo Go 시연을 독립 APK의 실행 검증이라고 설명하지 않습니다.
- Android 앱 화면을 녹화합니다. HTML 설계 미리보기는 필요할 때만 ‘설계안’으로 표시합니다.
- 앱에 개인 기록이 있으면 삭제 영향을 확인한 뒤 별도 시험 상태를 준비합니다. 영상에 알림·계정·개인정보가 들어가지 않게 합니다.
- 아래 시간은 편집 계획입니다. 실제 사용 소요 시간이나 학습 성과 측정값이 아닙니다.

녹화에서 저장 복원을 직접 보여주려면 저장 완료를 기다린 뒤 앱을 완전히 닫고 다시 여는 장면을 포함합니다. 녹화하지 않은 동작은 문서의 사용자 확인 보고와 구분해 설명합니다. 실제로 관찰되지 않은 성공 화면을 편집해 넣지 않습니다.

## 첨부할 화면 — 아직 미촬영

1. 학습 홈: 방법론 진입과 첫 미션 경로
2. 하네스 상세: 공식 자료·교육용 예시·출처 구분
3. 문항 피드백: 선택과 판정 상태
4. 실습 실패 결과: 빈 값만 차단했을 때 공백 입력 실패
5. 실습 통과 결과: 세 입력 비교와 미션 완료
6. 내 기록: 저장 상태와 현재 진행

캡션에 촬영일·환경(Expo Go/APK)·앱 버전·표시한 동작을 적습니다. 실제 이미지가 준비된 뒤 본문과 연결하며, 현재는 존재하지 않는 파일 링크를 넣지 않습니다.
